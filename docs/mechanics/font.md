# Font: fonty in HD

The bitmap font `fonty` redrawn in HD and kept next to the 2008 atlas in
`ui.mset`; `Render.Font` draws it.

## Journal

### Сессия: шрифт fonty в HD, v3.0.4 (2026-09-29)

Атлас fonty перерисован DALL-E по образцу 2008 (как до этого логотип) и
вычищен скриптом против оригинала. В ui.mset: `fonty` - новый, 1024x1024,
клетка 64; `fonty-2008` - старый, байт в байт. Вернуть вид 2008 - одна
константа FontFileName в dpr.

#### Сверка с 2008 (по клеткам, скриптом)
- Раскладка цела: все 256 клеток на месте, ни одна не опустела и не
  появилась. Сдвиг рамки чернил - медиана 0.8 px, максимум 1.75 px в
  пикселях 2008 (':' и ';'). Толщина штриха в среднем +5%.
- Квадраты-заглушки ('"', '=', '‡', '€', 'Ў', 'Є', ...), '&' в виде '_',
  'µ' в виде 'В', черта над строчной 'o' - всё это было в атласе 2008 и
  сохранено как есть. Из текстов игры (lang, level, monsters) на
  заглушку попадает только '=' в полях note, которые не рисуются.
- DALL-E оставил около 1000 px чужих чернил у границ клеток (кусок
  заглушки '=' под '-' и т.п.). Правило чистки: фрагмент выживает в
  клетке, только если глиф 2008 этой клетки имеет чернила там же.
- Цвет чернил у DALL-E уехал в (204,246,0); перекрашено в (188,255,0)
  2008 с сохранением яркости - иначе ячейки сложности в меню
  (MenuInkColor) разошлись бы с подписью.
- Внутри каждой клетки - пустая рамка 2 px: линейный фильтр читает
  полтекселя за Src, соседняя заглушка иначе просвечивала бы полосой.

#### Решения (аргументы в скобках)
- Клетка 64, не 80 и не 56 (симуляция выборки на 1080p: мелкий текст
  уменьшается из 64 в ~2.4 раза - билинейный ещё держит; отсчёт хеншина
  до 132 юнитов растёт до ~370 px - 56 уже мылит; 1024 - степень двойки).
- Render.Font берёт клетку из размера картинки (FAtlasCellPx), атлас
  обязан быть квадратом со стороной кратной 16 - иначе EFontError с
  размерами. FontCellPx = 28 остаётся мерой дизайна 2008: Menu и
  TitleCard делят на него пиксели, замеренные на старом атласе, и эти
  доли верны для любого размера.
- Фильтр - nearest по умолчанию (FontFiltering в dpr). Живой прогон
  трёх режимов: линейный не дал заметной чёткости, зато съел твёрдый
  ступенчатый край - а по нему шрифт 2008 и узнаётся. Опасение, что
  nearest потеряет штрихи при уменьшении из 64, в игре не подтвердилось.
- Атлас в двух текстурах, nearest и linear; TMoonFont.Filtering выбирает
  по размеру текста: linear / nearest / linear мелкий + nearest крупный.
  Не одна текстура с переключением фильтра: пакетный рендер читает
  фильтр в момент сброса, и весь кадр ушёл бы в последний режим.
  Клавиша N (DEBUGKEYS) листает режимы, имя - в заголовке окна. Атлас
  2008 - nearest в любом режиме, линейной копии у него нет.
- TitleCard свой TMoonFont не настраивает и рисует линейно.

#### Открытое
- Живой прогон: HUD-тикер в движении (мерцание при уменьшении), бегущая
  строка (ушла в 3.0.8 - вместо неё терминал), отсчёт 3-2-1, меню с
  флагами, TitleCard.
- Широкие Ъ Ы Ю касаются краёв клетки, а крупный текст идёт с
  нахлёстом 20% - проверить глазами, не режется ли край.

#### Тег
Коммиты серии: Read the font cell size from the atlas image; Redraw the
font atlas at 1024x1024 (3.0.4); Update the docs for 3.0.4; Let the font
filtering be cycled live (N); Draw the redrawn font nearest by default;
Note the font filtering in the 3.0.4 docs. **3.0.4** - тег на последнем.
